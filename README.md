## ✨ Features

- **Immersive 3D UI**: Smooth, hardware-accelerated animations built with Framer Motion.
- **Modern Design**: Clean and professional aesthetics powered by Tailwind CSS 4.0.
- **Dynamic Content**: Centralized content management via a dedicated data layer.
- **Responsive Architecture**: Flawless experience across desktop, tablet, and mobile devices.
- **Performance Optimized**: Built on Vite and React 19 for lightning-fast load times.

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs/)
- **Typography**: Inter & JetBrains Mono

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have the following installed on your local machine:

- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/arpit-portfolio.git
   cd arpit-portfolio
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📂 Architecture

The project is structured for scalability and maintainability:

```text
src/
├── components/          # Modular UI components
│   ├── about/           # About & Competitive Programming sections
│   ├── common/          # Reusable primitive components (GlowCards, Buttons)
│   ├── contact/         # Contact forms & Footer
│   ├── hero/            # Landing section
│   ├── navbar/          # Navigation system
│   ├── projects/        # Project showcase
│   ├── skills/          # Skills & Experience timelines
│   └── widgets/         # Advanced 3D components (e.g., TagCloud)
├── data/
│   └── portfolio.ts     # Centralized content management
├── lib/
│   └── utils.ts         # Utility functions (Tailwind class mergers, etc.)
├── App.tsx              # Main application layout and scroll logic
└── main.tsx             # Application entry point
```
